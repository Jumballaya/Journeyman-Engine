# Strike Wing 1942

A 1942-style vertical shooter built on Journeyman Engine — the engine's
integration test and showcase.

- **Title screen** with how-to-play and options (music/SFX volume, CRT filter, fullscreen)
- **Stage 1 · Pacific Dawn** — open ocean and islands
- **Stage 2 · Jungle Front** — tougher squadrons over enemy territory
- **Stage 3 · Iron Fortress** — a three-phase flying-fortress boss in a storm
- Results screen between stages (kills, accuracy and no-miss bonuses),
  game over with continue, victory screen with credits
- Pause menu (resume, restart stage, main menu, quit), saved high score

## Controls

| | Keyboard | Gamepad |
|---|---|---|
| Move | Arrows / WASD | Left stick / D-pad |
| Fire (hold) | Space / Z | A / Right trigger |
| Bomb (clears bullets) | X | B / X / Left trigger |
| Pause | Esc / P | Start |
| Fullscreen | F11 | |

Pickups: **P** raises your weapon level (max 3), **+** is an extra ship, the
shield icon is an extra bomb. Losing a ship drops one weapon level.

## Build & run

From the repository root: `./scripts/play-demo.sh` (or `--export` for a
standalone app). Manually:

```bash
cd demos/strike_wing/assets/scripts && npm install && cd ../..
jm build && jm run                 # or: jm pack && jm run build/strike-wing-1942.jm
jm export                          # dist/Strike Wing 1942.app
```

## How it's made

Everything gameplay is in `assets/scripts/` (AssemblyScript):

| Script | Role |
|---|---|
| `director.ts` | stage timeline (waves), music, effects, banners, stage end |
| `player.ts` | movement, weapon levels, bombs, damage, respawn |
| `enemy.ts` | all regular enemies; behavior from params (pattern, fire mode, drops) |
| `boss.ts` | the three-phase boss |
| `scroller.ts` | parallax backgrounds (ocean / jungle / storm) |
| `hud.ts`, `pause.ts` | HUD bindings and the pause menu |
| `title.ts`, `stage_clear.ts`, `game_over.ts`, `victory.ts` | menus and screens |
| `lib/session.ts` | the run's state (score, ships, stage, signals) and the high score |
| `lib/presentation.ts` | settings defaults, CRT choice, menu sounds and transitions |
| `lib/waves.ts` | authored formations and stage schedules |
| `lib/combat.ts`, `lib/util.ts` | explosion recipes, playfield constants and score presentation |

Reusable mechanics come from [`@jm/runtime`](../../docs/runtime-gameplay.md):
session containers, saved settings, screens, sprite shadows, projectile patterns,
timers and timelines, menus, health, checkpoints, math,
input vectors, tile grids and HUD helpers. For example, the director dispatches
waves with `launches.update(dt, launch)` and enemies fire with
`spreadShot.fan(x, y, aimAtPlayer(), 3, 0.44)`.

Run the compiled-script regression checks from the repository root:

```sh
node --test cli/internal/stdlib/tests/*.test.mjs
```

Screens are HTML/CSS in `assets/ui/`; transitions and the CRT filter are
shaders in `assets/shaders/`.
